# Segurança em Redes Corporativas (Segurança Computacional, UnB, 2026/1)

Projeto em grupo no qual avaliamos a infraestrutura de uma empresa fictícia (SecureTech).

O que foi feito

Captura e análise de tráfego HTTP vs HTTPS com Wireshark, incluindo o handshake TLS 1.2
Inspeção de certificados e cadeias de confiança (google.com, nubank.com.br, gov.br) com OpenSSL
Varredura de serviços com Nmap e classificação de riscos (SQL Injection, CUPS, MariaDB exposto)
Firewall com ACLs no Cisco Packet Tracer seguindo o princípio do menor privilégio, com testes de validação
Estudo do ataque DDoS e mitigações

Ferramentas: Wireshark, OpenSSL, Nmap, Cisco Packet Tracer
Relatório completo: disponível em Trabalho3_Seg_Comp-2.pdf
